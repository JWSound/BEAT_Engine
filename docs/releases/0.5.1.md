# BEAT Engine 0.5.1

Hotfix based on 0.5.0 for first-use Metal initialization. Numerical kernels and
solver defaults are unchanged.

- Metal-specific bundles require Metal before compilation. Dependency failures
  propagate with their original error rather than caching an unavailable backend.
- Source and compiled Metal worker entry points do not silently fall back after
  a failed bundle import.
- The source-entry Deploy worker reports live backend availability separately
  from its list of supported solve paths.
- Regression coverage injects an import failure and verifies recovery using the
  same cache, plus CPU-only loading and device-readiness reporting.

Deploy clients should check both Metal solve support and `backends.metal.available`.
Use a new application runtime cache ID when distributing this update.
