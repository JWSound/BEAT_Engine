# BEAT Engine 0.6.0

This release corrects projected FEM-BEM interface coupling and batches Metal
field evaluation. Applications must adopt the published wheel and its SHA-256
and restart workers after upgrading.

## Numerical correction and compatibility

- Use the same facewise-constant (DP0) interface flux for FEM weak loading and
  BEM radiation, conserving pressure-weighted work as well as total flux.
- Reject rank-deficient or poorly conditioned interface coefficient transfers.
  Some previously accepted triangulations, including single-triangle and
  three-colourable patches, now fail explicitly. Use an admissible interface
  triangulation and verify convergence; refinement alone does not guarantee
  admissibility. See `docs/Projected interface flux.md`.
- Factor monolithic CPU/Metal Float32 coupled systems in Float64 on the host,
  retaining Float32 output traces and GPU operator precision. This improves
  coefficient accuracy in badly scaled electrodynamic systems.
- Describe `interface_normal_derivative` as projected DP0 coefficients: each
  physical face flux is the mean of its three vertex-indexed coefficients.
  Use `bem_boundary_neumann` for physical per-face flux.

Worker protocol and result schemas are unchanged. Numerical values can change
because the interface weak load has been corrected; prior results should be
recomputed and checked.

## Backend execution

- Preserve the requested backend when building a coupled system without a cache.
- Batch Metal field outputs per excitation while preserving each output's
  partition and reduction order. Update compiled Metal precompile coverage.

## Qualification

Publication requires successful Linux, Windows and macOS CPU CI, Metal host
tests and the sweep benchmark on the exact tagged main commit. Final wheel
qualification must include CPU reference tests, Boundary Lab integration,
relevant CUDA coupled checks and Apple Silicon Metal device tests.

Record final artifact SHA-256 values, hardware, commands and outcomes in the
GitHub release before publishing. Contributor validation and hosted Metal
compilation are supporting evidence, not final-artifact GPU qualification.
