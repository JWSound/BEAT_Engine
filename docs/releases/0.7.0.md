# BEAT Engine 0.7.0

This release adds exterior acoustic field gradients for particle velocity and
acoustic intensity visualization with BEAT CPU and CUDA.

## Field evaluation

- Negotiate the new `pressure_gradient_v1` field quantity explicitly.
- Return complex pressure and XYZ pressure derivatives in a C-order `(point, 4)`
  array, preserving coordinate precision and phasor conventions.
- Use analytic kernel derivatives and adaptive CPU quadrature corrections near
  boundary panels. Gradient requests use fourth-order quadrature and separate
  geometry-cache entries.
- Preserve the existing pressure-only evaluation path. Metal and ROCm do not
  advertise the new gradient capability. Boundary-surface samples are unsupported.

Applications must adopt the published wheel and SHA-256 pin and restart workers
after upgrading. Older workers cannot provide the new field quantity.

## Validation

Contributor validation includes 236 Python tests, the standalone Julia reference
gate, 57 CPU/CUDA numerical checks, and two Boundary Lab integration tests through
real CPU/CUDA workers. Checks cover binary layout, finite differences, symmetry,
phasor signs, near-panel solid angles, and radiating monopole velocity/intensity.
No performance claim is made.

The release workflow requires successful CI on the exact tagged main commit,
builds the wheel and source archive, smoke-tests wheel installation, and publishes
SHA-256 checksums with the artifacts.
