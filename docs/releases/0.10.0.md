# BEAT Engine 0.10.0

Level 3 speaker exports can train and validate continuous interior models over a configured frequency band. Array prediction tools can evaluate the model at in-band frequencies to predict how terminal voltage and external acoustic loading excite the cabinet. [#114](https://github.com/JWSound/BEAT_Engine/pull/114)

Deploy workers can assemble continuous speaker operators in bounded host memory. CUDA export workers use complex FP64 cuDSS for full-order interior solves, reuse sparse analysis across compatible matrices, and batch external-source audit loads. [#115](https://github.com/JWSound/BEAT_Engine/pull/115), [#116](https://github.com/JWSound/BEAT_Engine/pull/116)

Restart persistent workers after upgrading so they load the new solver and advertise its capabilities.
