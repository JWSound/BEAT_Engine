# BEAT Engine 0.9.0

Coupled FEM/BEM solves now support prescribed axial velocity on exterior surfaces, interior surfaces, or both within one coupled model. A shared motion axis and per-boundary weights define the normal velocity on each assigned surface. Clients can check the worker capability `coupled_source_profiles` before submitting a coupled axial request. [#99](https://github.com/JWSound/BEAT_Engine/pull/99), [#110](https://github.com/JWSound/BEAT_Engine/pull/110)

This release also updates the CUDA path for replaying resident interface data. [#106](https://github.com/JWSound/BEAT_Engine/pull/106)

Restart persistent workers after upgrading so they load the new solver and report the updated capabilities.
