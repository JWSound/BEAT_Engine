# BEAT Engine 0.5.0

This minor release enables Boundary Lab Deploy's Metal solver on Apple silicon,
extends exterior transducers, and adds opt-in FEM wall losses. Applications must
adopt the published wheel with its SHA-256 pin and restart workers after upgrading.

## Features and execution

- Add the Metal Deploy solver path, including reusable assembly and field caches,
  host near/image corrections, frequency sweeps and cached field evaluation.
  Metal performs assembly and field evaluation; dense LU and ROM GMRES remain on
  the CPU. Workers advertise `deploy_solver_backends` for capability negotiation.
- Extend exterior transducers to Metal, Float32, and x/xy symmetry. Symmetry-plane
  caps and off-plane seams fail explicitly. CUDA and ROCm exterior-transducer
  support remains unqualified; see the exterior-transducer precision documentation
  for accuracy limits and supported configurations.
- Add opt-in `thermoviscous_wall_losses="thin_boundary_layer"` for supported
  unlined stationary rigid walls in bounded air. The default remains off.
- Evaluate independent exterior field outputs together per excitation, reuse
  Metal field buffers, remove redundant fused-assembly zero fills, and repair
  exterior Metal precompile coverage.
- Suppress console windows for persistent workers on Windows.

## Compatibility

Worker protocol v1 and result schema v2 are unchanged. Exterior contract v3 and
the new capability fields are additive. Existing application pins are unchanged
by this engine release; macOS application packaging is a separate deliverable.

## Qualification

Release publication requires the Linux, Windows and macOS CPU CI suites, Metal
host tests and sweep benchmark for the exact tagged main commit. Installed final
artifacts additionally require CPU reference and exterior/coupled agreement
gates, Apple-silicon Metal hardware qualification, and Boundary Lab Deploy
CPU/Metal integration checks. Exact artifact SHA-256 values, hardware details
and qualification outcomes are recorded in the GitHub release before publication.
