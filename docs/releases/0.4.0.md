# BEAT Engine 0.4.0

This minor release adds exterior transducers, improves CPU and Metal execution,
and updates CUDA support. Applications must adopt the published wheel with its
SHA-256 pin and restart existing workers after upgrading.

## Features and execution

- Add contract v3 exterior electrodynamic transducers and the mutual radiation-
  impedance matrix. Existing v1/v2 ideal-source requests and result schema v2
  remain supported. Exterior transducers currently require Float64 and symmetry
  off or ground; unsupported component/backend combinations fail explicitly.
- Add opt-in rigid-translation exterior sources, source-driver rigid-ground
  support, and complete CPU near correction for multiple symmetry images.
- Improve CPU SIMD assembly/field evaluation, sweep solution reuse, compiled
  workloads, Metal packed/combined assembly, and coupled sweep pipelining.
- Add opt-in CPU Float32 LU residual refinement; emit successful aggressive
  completion before cleanup and parse field observation points once per request.
- Upgrade CUDA.jl to 6.4.2 for Pascal compatibility on Windows, preserving the
  packaged CUDA precompile bundle. Repair shared workload tests in accelerator
  qualification environments.

## Default changes and compatibility

- CPU regular quadrature now defaults to fixed base order (normally order 4)
  rather than wavelength-selected order. This changes numerical results and can
  increase assembly time. Explicit `regular_quadrature_mode="wavelength"`
  remains a CPU opt-in.
- CPU coupled solves now default to reductions and Float64-assembled dense systems
  with refined Float32 LU. Dense-system memory can be approximately three times
  the previous default; refinement fallback can require more. Set
  `BLAB_COUPLED_DENSE_REFINEMENT=0` to disable refinement. A plain Float64 LU also
  requires disabling refinement when `BLAB_COUPLED_DENSE_FLOAT64=1` is set.
- Unsupported passive radiators and exterior transducers below contract v3 are
  now rejected instead of being silently treated as rigid components.
- Worker protocol v1 and result schema v2 are unchanged; contract v3 is additive.

## Qualification

The integrated source passed CPU CI on Linux, Windows and macOS, the Metal host
and precompile gate, and the sweep benchmark gate. The standalone Julia CPU
reference suite and CUDA hardware qualification passed on Windows with an
RTX 2080 Ti (Julia 1.12.7 for CUDA). This is not a new Metal or ROCm hardware
qualification; Metal hosted CI has no GPU.

Final wheel/sdist SHA-256 values and installed-artifact CPU/CUDA and Boundary Lab
integration outcomes are recorded in the GitHub release before publication.
