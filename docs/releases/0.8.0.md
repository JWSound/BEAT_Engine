# BEAT Engine 0.8.0

This release adds qualified ROCm solver and retained-field capabilities for the
AMD Radeon RX 7600 on Windows, plus benchmark and runtime verification tools.
Applications must adopt the published wheel and SHA-256 pin and restart workers
after upgrading.

## ROCm capabilities

- Support positive-time phasors, near-singular corrections, wavelength-driven
  quadrature, exterior electrodynamic transducers and interface radiation.
- Improve coupled-system precision and qualify thermoviscous wall losses.
- Add transducer condensation, speaker rank analysis and ROM response export,
  with explicit host analysis where required.
- Enable Deploy boundary and ROM array solves and reduce identity-upload costs.
- Add analytic retained pressure gradients for particle velocity and intensity,
  preserving complex output layout, precision and phasor conventions.
- Improve regular-pair quadrature performance and resource teardown. Detailed
  workload-specific measurements and limitations are in the RX 7600 reports.

Worker protocol and existing result schemas remain unchanged. Clients must
negotiate advertised capabilities. This qualification does not establish support
for every AMD GPU or operating system.

## Qualification and known limitations

The integrated solver source passed the RX 7600 hardware suite on Windows with
HIP 7.2 and Julia 1.12.6, the standalone CPU reference gate, and application and
relocated Deploy integration. Release CI requires CPU validation on Linux,
Windows and macOS, Metal host checks and the sweep benchmark on the exact tagged
main commit. Final artifact hashes and installed-wheel qualification results are
recorded in the GitHub release before publication.

The optional historical q1/s1 coupled validator exceeds its diagnostic-only
Float32 host-LU voltage-flux threshold (0.002337558 versus 0.002) on an
ill-conditioned fixture. Production ROCm and condensed voltage-flux relative
errors were 5.433864e-6 and 6.544884e-7. No tolerance was relaxed. That failed
validator also left a Julia process requiring a machine restart; it is not a
passing qualification result. See integration PR #104 for the validation record.

CUDA and Metal device qualification is not implied by hosted CPU/Metal host CI
or the RX 7600 results.
